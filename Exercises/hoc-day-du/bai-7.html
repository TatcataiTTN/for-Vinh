Subquery Không Tương Quan

Bài 7

Chạy độc lập, một lần duy nhất

Sản phẩm chưa từng bán được
SELECT * FROM products
WHERE productCode NOT IN (
  SELECT productCode FROM orderdetails
);
Đơn hàng gần nhất
SELECT * FROM orders
WHERE orderDate = (
  SELECT MAX(orderDate) FROM orders
);

Truy vấn con bên trong được tính TRƯỚC, kết quả của nó được điền vào truy vấn ngoài, rồi mới thực thi truy vấn ngoài.

Subquery Tương Quan

Bài 7

Sử dụng giá trị của truy vấn ngoài trong WHERE

So sánh với trung bình cùng loại
SELECT * FROM products p
WHERE quantityInStock > (
  SELECT AVG(quantityInStock) FROM products
  WHERE productLine = p.productLine
);
Dùng EXISTS thay cho IN
SELECT * FROM products p
WHERE EXISTS (
  SELECT productCode FROM orderdetails
  WHERE productCode = p.productCode
);

Với mỗi dòng của truy vấn ngoài, truy vấn con chạy lại và dùng giá trị p.productLine/p.productCode của chính dòng đó — nên gọi là 'tương quan'.

Subquery Ở SELECT Và FROM

Bài 7

Truy vấn con không chỉ dùng trong WHERE

Ở mệnh đề SELECT
SELECT orderNumber, quantityOrdered,
  (SELECT productName FROM products
   WHERE productCode = o.productCode) AS Ten
FROM orderdetails o;
Ở mệnh đề FROM (như 1 bảng tạm)
SELECT T.nam_thang, COUNT(*)
FROM (
  SELECT orderNumber,
    SUBSTR(orderdate,1,7) AS nam_thang
  FROM orders
) AS T
GROUP BY T.nam_thang;

Khi subquery đứng ở mệnh đề FROM, kết quả của nó được coi như một bảng dữ liệu tạm thời để truy vấn ngoài tiếp tục xử lý.
