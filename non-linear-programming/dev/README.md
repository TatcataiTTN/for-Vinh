# Mã nguồn sinh site (ảnh chụp từ thư mục dự án NLP-work)

Đây là bản sao để công khai và để GitHub Actions kiểm tra. Các script `build/` cần cấu trúc thư mục dự án gốc
(thư mục `Slides/` và `for-Vinh/`) nên **chỉ chạy được đầy đủ trong thư mục dự án**; `verify/verify_all.py`,
`code/exercises/test_reference.py` và `code/cvxpy_bai_tap/` chạy độc lập (xem `.github/workflows/nlp-verify.yml`).
Hướng dẫn chi tiết: `docs/DEVELOPMENT.md` hoặc trang https://tatcataittn.github.io/for-Vinh/non-linear-programming/phat-trien/
